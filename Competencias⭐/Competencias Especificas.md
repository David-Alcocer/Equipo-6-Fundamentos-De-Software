# Competencias Especificas 
---

## ¿Cómo se promueven las competencias específicas en el desarrollo de un producto de software?

### Uso de GitHub para control de versiones y colaboración

- Se emplea GitHub para llevar un registro exacto de los cambios en el código.

- Permite la colaboración simultánea, asegurando que todos los integrantes trabajen sobre la misma base actualizada.

- Fomenta la disciplina en el manejo de repositorios y ramas.

### Elaboración de README.md

- Se redacta un archivo README.md donde se documenta el propósito del proyecto, los pasos de instalación y el uso del producto.

- Esto desarrolla la capacidad de comunicar de forma técnica y clara.

- Refuerza la importancia de la documentación como parte esencial del producto final.

### Distribución de tareas entre integrantes

- Se asigna a cada miembro un rol definido: estructurar el HTML, documentar avances, o revisar el trabajo de otros.

- Se practica la organización y la responsabilidad individual dentro del trabajo colectivo.

- Favorece la eficiencia y el cumplimiento de plazos.

### Aplicación práctica de la teoría en HTML

- Se construye la estructura del producto directamente en lenguaje HTML.

- La práctica permite afianzar lo aprendido en teoría, integrando conocimiento y habilidad técnica.

- Se generan resultados visibles que refuerzan el aprendizaje.

### Resolución de conflictos en equipo

- Se enfrentan y solucionan discrepancias en el código o la organización mediante comunicación y acuerdos.

- Esto promueve el pensamiento crítico y la toma de decisiones.

- Refuerza competencias de trabajo en equipo y liderazgo.
